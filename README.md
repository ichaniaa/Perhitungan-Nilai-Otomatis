# Aplikasi Perhitungan Nilai Ujian Otomatis

## Deskripsi
Aplikasi Perhitungan Nilai Ujian Otomatis merupakan aplikasi berbasis Console TypeScript yang digunakan untuk menghitung nilai rata-rata siswa, menentukan status kelulusan atau remedial, serta memberikan predikat penghargaan kepada siswa berdasarkan hasil nilai ujian.

## Teknologi yang Digunakan
* TypeScript
* Node.js
* Visual Studio Code
* Git dan GitHub

## Cara Menjalankan Program
1. Clone repository.
2. Buka folder proyek di Visual Studio Code.
3. Install dependencies jika diperlukan.
4. Jalankan program menggunakan TypeScript.

## Fitur Aplikasi
* Input nama dan nilai siswa.
* Menghitung nilai rata-rata ujian.
* Menentukan status kelulusan atau remedial.
* Memberikan predikat penghargaan berdasarkan nilai.
* Menampilkan hasil perhitungan nilai siswa.
